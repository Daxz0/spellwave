# About

This is my plugin for a super duper cool ultra-customizable spell system! its still WIP, but feel free to check out the journal to see what ideas i have! (or if youre a reveiwer :) )

To use the imbuement table, use /itemh give imbuement_table to get one. Crafted support will be added later down the lime.
You need to have the imbuement table placed on top of an amethyst block, and place blackstone as your magic crafting area.

Right click to place items into each slot, each ring expanding from the enchantment table is a "layer", and layers will run after another depending on the layer modifier.

There is currently only support for amethyst shard and rabbit foot, more more more will be added later on!

# Installation
This plugin is made for 26.1.2 and for **PaperMc** specifically. Install [PaperMC](https://papermc.io/), and then drag this plugin into the plugins folder.
You can find the JAR file in the releases of this repository.

Awaiting modrinth approval [here](https://modrinth.com/plugin/spellwave). Download releases for now.
