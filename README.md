# spellwave

this is my plugin for a super duper cool ultra-customizable spell system! its still WIP, but feel free to check out the journal to see what ideas i have! (or if youre a reveiwer :) )

to use the imbuement table, use /itemh give imbuement_table to get one.
you need to have it on an amethyst block, and place blackstone as your magic crafting area.

(the cinnabar blocks are optional and only for flair)

then place your table down, right click it and kaboom!

place items into each slot, each ring expanding from the enchantment table is a "layer", and layers will run after another depending on the layer modifier (unadded yet)

there is currently only support for amethyst shard and rabbit foot, but this is just a demo, more more more will be added later on!
